# hxyfront-62007 植物标本馆入库

源提示词编号：9

植物标本馆压制标本入库前端项目。工作人员在馆藏登记台录入采集号、物种名称、采集地点、海拔、生境描述、采集人、压制状态、鉴定状态和馆藏位置。页面包含入库队列、鉴定状态筛选、采集地点信息卡、馆藏柜位记录和单份标本详情。

## 登记规则

- 采集号用过即不可再分配（含已作废记录）
- 新标本先进入入库队列，鉴定接受后才能选柜位
- 柜位被占用时提示换位，不覆盖已有记录
- 作废必须填写原因；作废即释放柜位，原记录保留可查

## 分层结构（规则 / 存档 / 页面状态分开承载，无外部依赖）

```
src/
  domain/    登记规则：types.ts 数据模型，rules.ts 纯函数规则与视图选择器
  data/      存档：archive.ts localStorage 持久化与种子数据
  state/     页面状态：useArchiveStore.ts（唯一数据源）、usePageState.ts（筛选/选中/提示）
  components/ 视图：登记台、入库队列、鉴定筛选列表、采集地点卡、柜位记录、单份详情
```

鉴定筛选、采集地点卡、柜位记录和单份详情均从同一份存档派生；规则校验不通过时不提交新状态，页面保持原状。
