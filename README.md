# hxyfront-62007 植物标本馆馆藏登记台

植物标本馆压制标本入库前端：工作人员可登记采集号、物种名称、采集地点、海拔、生境、采集人、压制状态、鉴定状态与馆藏柜位，页面包含入库队列、鉴定状态筛选、采集地点信息卡、馆藏柜位记录与单份标本详情。

## 业务规则

- **采集号唯一**：采集号一经分配即永久占用；标本作废后采集号仍不可再次分配（作废记录保留）。
- **先鉴定、后上柜**：新登记标本一律进入待鉴定队列；鉴定接受（须填写定名）后才能选择柜位。
- **柜位不可覆盖**：上柜/换位时目标柜位若被占用，操作被拒绝并提示换位，已有记录不会被覆盖。
- **作废留痕**：作废必须填写原因；作废后释放柜位，原始字段与完整操作历史全部保留。
- **条件不满足保持原状**：任何规则校验失败都不会修改数据，表单输入与列表状态保持不变。

## 架构（三层分离，无额外运行时依赖）

```
src/
  domain/        登记规则层（纯 TypeScript，无 React、无存储）
    types.ts       领域模型
    rules.ts       登记/鉴定/上柜/换位/作废纯函数（入参 registry 不可变）
    cabinet.ts     柜位网格（A/B 两区 × 12 列 × 4 层）
    selectors.ts   鉴定筛选、指标、地点卡、柜位占用等只读派生
    seed.ts        初始示例数据
  archive/       存档层（localStorage 序列化，框架无关）
    storage.ts
  state/         页面状态层（React hook，唯一持有 registry）
    useRegistry.ts
  components/    队列筛选 / 地点卡 / 柜位图 / 单份详情 / 登记表单
```

鉴定筛选、采集地点卡、柜位记录与单份详情从**同一份** registry 经 selector 派生，不各自保存副本。
